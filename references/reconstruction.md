# Reconstruction

Run `node scripts/ui-re.mjs reconstruct --input IR --output TASK [--shadcn]`. This validates the manifest and creates `reconstruction.json` and `TASK.md`; the coding agent writes the implementation. No model provider or API key is used. The default adapter is React/TSX; alternative adapters implement `src/ports/FrameworkAdapter.ts` without changing capture or preprocessing.

Inspect a desktop and mobile screenshot, the corresponding tree regions, typography/assets and responsive deltas. Infer a small design system from repeated evidence, then choose semantic component boundaries and variants. Preserve CSS intent such as percentage widths and max-width constraints rather than hardcoding every measured bound. Verify inferred breakpoints against adjacent captures. Build clean components rather than reproducing source framework wrappers.

Separate generic controls, shared layout and domain content according to the target project's conventions. Keep source editable. Reuse assets only within the user's authorization; load local asset files by manifest ID. Preserve observed headings, labels, links, keyboard controls and interaction state. Add explicit `data-ui-re-id="n-..."` to representative geometry anchors when clean markup differs from captured structure; do not add hidden duplicate elements to manipulate verification.

When shadcn is requested, use editable source components for controls with matching semantics: buttons, dialogs, tabs, inputs, selects, menus and tooltips. Customize their appearance and focus/hover/open states to captured evidence. Set shadcn-compatible CSS variables for background/foreground, card, muted, primary, accent, border, input, ring and radius from the inferred palette. Choose actual values from the evidence, not preprocessing names. Use custom components for domain structures. Obtain approval before installing dependencies not already authorized; component choice does not imply permission to modify the host.

Serve the target through its normal development command. Render at all reference viewports/states and inspect verification reports before changing code. Diagnose layout/typography/asset differences from both geometry and pixels. Check observed interactions manually when automated states do not cover them. Reconstruction is complete only after the skill's acceptance/iteration exit condition, not after preparation files or a first screenshot exist.
